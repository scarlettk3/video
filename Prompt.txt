Develop a complete real-time multi-agent framework for detecting and mitigating Link Flooding Attacks (LFA) in an SDN environment using Ryu and Mininet.

The system must contain three AI agents that operate in a closed-loop real-time setup:

1. **Agent 1 — LFA Traffic Generation Agent:** Reuse my already-trained tabular GAN `Generator` as a frozen model. An epsilon-greedy bandit should control the adversarial/evasion mode of the generator. The bandit reward should be based on the attack objective minus the Detection Agent's confidence. The generator must operate during the live experiment, not generate attack samples offline. Its generated feature profiles should be translated into bounded traffic-generation parameters and used to produce controlled LFA traffic in a Mininet. The generated traffic must remain within an isolated experimental environment.

2. **Agent 2 — Detection Agent:** Reuse my existing frozen ENAS+GAN classifier, preferably the `enas_with_gan` model, without retraining or changing its architecture. Integrate it directly with the Ryu controller so that Ryu continuously collects OpenFlow statistics, extracts exactly the same features used during training, applies the same preprocessing/scaler, and sends each completed feature window to the frozen classifier. The detector must output the LFA prediction and detection confidence in real time.

3. **Agent 3 — DQN Mitigation Agent:** Use my DQN mitigation agent trained offline in an environment that models link congestion and many-flow crowding. When Agent 2 detects an LFA, the DQN should receive the current network state, select an appropriate mitigation action, and allow Ryu to apply the corresponding routing, flow-management, rate-control, or other safe mitigation policy in the SDN testbed.

The complete system should work as a real-time closed loop:

`Frozen GAN + Bandit → Live LFA Traffic → SDN Network → Ryu Statistics → Feature Extraction → Frozen ENAS+GAN Detector → DQN Mitigation → Ryu Network Action`

Additionally, Detection Agent confidence must be fed back to Agent 1 so that the epsilon-greedy bandit can dynamically select attack/evasion modes according to:

`Reward = Attack Effectiveness − Detection Confidence`

This feedback must happen during the live experiment so that Agent 1 dynamically adapts while Agent 2 simultaneously performs real-time detection.
